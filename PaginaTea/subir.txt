Todo lo que tenes que cambiar cuando ganemos !!!!

<>  Crear un nuevo .env en tea_mo_backend/ con esto: 
SECRET_KEY=key
DEBUG=False
ALLOWED_HOSTS=tudominio.com,www.tudominio.com

FRONTEND_URL=https://tudominio.com
BACKEND_URL=https://api.tudominio.com

EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_HOST_USER=teamo.notificaciones@gmail.com
EMAIL_HOST_PASSWORD=tu-contraseña-de-aplicación
EMAIL_USE_TLS=True
DEFAULT_FROM_EMAIL=TEA-MO <teamo.notificaciones@gmail.com>

DATABASE_URL=postgres://usuario:contraseña@host:puerto/nombre_db
(Si creamos la base en postgresSQL)

Crear la key 
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"




Cambiar en settings.py
Modificar esto
CORS_ALLOWED_ORIGINS = [
    "https://tudominio.com",
    "https://www.tudominio.com",
]

Agregar esto 
CSRF_TRUSTED_ORIGINS = [
    "https://tudominio.com",
    "https://api.tudominio.com",
]

Si cambiamos de SQLite a Postgres hacer esto (Si no dejarlo asi)
import dj_database_url
DATABASES = {
    'default': dj_database_url.config(default=config('DATABASE_URL'))
}

Si ponemos cache redis poner esto (Si no dejarlo asi)
CACHES = {
    'default': {
        'BACKEND': 'django.core.cache.backends.redis.RedisCache',
        'LOCATION': config('REDIS_URL', default='redis://127.0.0.1:6379'),
    }
}


Cambiar en el Front-end !!! 

En src/pages/Blog.jsx
Cambiar la const API_URL por:
const API_URL = 'https://api.tudominio.com/api/preguntas/'

En src/pages/Eventos.jsx 
Cambiar las constantes API_URL y SUSCRIBIRSE_URL por: 
const API_URL = 'https://api.tudominio.com/api/eventos/'
const SUSCRIBIRSE_URL = 'https://api.tudominio.com/api/eventos/suscribirse/'


Poner esto en la terminal del servidor 
python manage.py migrate
python manage.py collectstatic --clear
python manage.py createsuperuser
